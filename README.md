Network Security IP Verifier
Project Overview


  This project is a Python-based utility designed to simulate a basic network firewall or Access Control List (ACL) mechanism. It demonstrates how logical programming and conditional rules can be applied to solve real-world problems in Cybersecurity and Network Infrastructure.

  
  
  As a Telecommunications Engineer transitioning into Data Analysis and Cybersecurity, I developed this script to practice and demonstrate:

Use of data structures (lists and strings)

Conditional logic for security decision-making

Clean and readable code principles

Technical Features



IP Blacklisting
Validates real-time user input against a predefined list of malicious or blocked IP addresses.

Access Control Simulation
Acts as a gatekeeping mechanism to determine whether an IP address is allowed or denied access to a system.

Dynamic Security Feedback
Provides clear console output that simulates logging and security auditing behavior.

How to Run

Make sure Python 3 is installed on your system.

Clone this repository:
